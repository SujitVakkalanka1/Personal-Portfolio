02 // FEATURED PROJECTS

HANDS-ON APPLICATIONS & ENGINEERING BUILDS

ClauseGuard AI

FULL-STACK AI & WEB3

An AI-powered contract clause risk detection tool, built for a hackathon around a mandatory blockchain payment requirement. A FastAPI backend uses the Google Gemini API to flag risky clauses in a contract, while a React/Vite frontend presents the analysis clearly. Payment for each analysis runs through the x402 protocol on Algorand — real blockchain settlement, not a mocked transaction.

Python FastAPI React Algorand Gemini API

X-AI Financial Reasoning Engine

EXPLAINABLE AI SYSTEM

A financial reasoning tool built around explainability: it takes in numerical financial data and doesn't just output a prediction, it shows the reasoning behind it. The goal was to make the "why" behind a financial output as visible as the output itself, not a black box.
