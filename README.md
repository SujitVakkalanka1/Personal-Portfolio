## ⚡ Overview

Personal portfolio of **Sujit Vakkalanka**, built with high-performance creative development standards: smooth inertia scrolling, procedural WebGL shader interactions, scroll-scrubbed typography illumination, responsive layouts, and an integrated dual-theme engine.

---

## 🛠️ Tech Stack & Architecture

- **Core**: React 18, Vite 6, JavaScript (ES6+)
- **Motion & Interactions**: GSAP 3, ScrollTrigger, Lenis Inertia Scroll
- **Graphics & Shaders**: Three.js, GLSL Shader Materials
- **Theming**: Dual Theme Engine (Obsidian Dark & Architectural Light) with instant local persistence
- **Hosting & Deployment**: Optimized for Vercel

---

## 🌟 Key Highlights

1. **Dual Theme Engine**: Fast toggle between Obsidian Dark Mode and Architectural Light Mode with local storage memory and high-contrast accessibility tokens.
2. **ScrollSpy Bottom Dock Navigation**: Floating pill navigation dock centered at the bottom of the viewport with real-time active section tracking.
3. **Step-by-Step Bio Illumination**: Sequential word illumination that highlights line-by-line upon entering viewport.
4. **Interactive Skill & Tooling Matrix**: Detailed card grid featuring progress tracks, subtext, and category filter tabs (`ALL`, `BUILDING WITH`, `EXPLORING`).
5. **Responsive Vector Wordmark**: Fully scalable dynamic vector brand mark with atmospheric glow and smooth scrolling animations.
6. **In-depth Case Studies**: Modal overlays detailing challenges, decisions, architecture, and impact for key engineering projects (ClauseGuard AI & X-AI Reasoning Engine).

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SujitVakkalanka1/sujit-portfolio.git
   cd sujit-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
