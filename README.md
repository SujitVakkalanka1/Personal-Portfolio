## 🛠️ Tech Stack & Architecture

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Variables, Grid, Flexbox, Micro-animations), ES6+ JavaScript.
- **Backend & Server**: Node.js static HTTP server with custom MIME-type resolution (PDF, JSON, WebP, Fonts).
- **Styling Philosophy**: Custom dual-theme design system (**Architectural Light** & **Obsidian Dark**) built with clean CSS custom properties — no heavy UI frameworks.
- **Dynamic Dataset**: Synchronized `portfolio.json` data store with client-side fallback engine.
- **Form Integration**: Direct FormSubmit AJAX integration sending messages directly to `vsbsujit883@gmail.com`.

## 🚀 Running Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/SujitVakkalanka1/Personal-Portfolio.git
   cd Personal-Portfolio
   ```

2. **Start the Local Server**:
   ```bash
   node server.js
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8000/` or `http://127.0.0.1:8000/`.
